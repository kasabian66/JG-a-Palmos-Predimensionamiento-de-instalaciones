# Predimensionamiento de instalaciones (Anteproyecto) — España

App Streamlit multipágina lista para Streamlit Community Cloud.

## Local
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud
- Subir a GitHub
- App → `app.py`

Incluye exportación a Excel y PDF.
